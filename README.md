# ReviewPortal — Shelton Tool-Hire Review Portal

A web application where customers browse hire equipment, calculate rental costs, and leave reviews. Staff manage the catalogue and moderate content from a back-office admin area.

## Repository Structure

| Directory | Description |
|-----------|-------------|
| [`BackEnd/`](BackEnd/) | ASP.NET Core Web API (.NET 8) — Clean Architecture |
| [`FrontEnd/`](FrontEnd/) | Client application |
